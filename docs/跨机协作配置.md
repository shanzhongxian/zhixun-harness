## 2. SwanLab：两种接法（选一种）

### 方案甲（官方推荐）：加协作者，各用各的 key

1. A 打开项目 `zhixun-engine` → 「概览」→ 右上角 **「分享」**；
2. 按用户名搜索 B 的账号；
3. 权限选 **「可开发」**（能建实验、改实验，但不能删项目）；
4. 点黑色 **「+」** 完成（每项目最多 10 名协作者）。

B 在自己机器上：

```python
import swanlab

swanlab.init(
    project="zhixun-engine",
    workspace="shanzhongxian",   # 关键：项目所有者的用户名，不填会建到 B 自己空间
    public=True,
)
```

B 用自己的 API Key 登录（`swanlab login` 或 `SWANLAB_API_KEY`）。

### 方案乙：共用 A 的 key（省事，但有串号风险）

官方对“多人共用”的两种做法：

```python
swanlab.login(api_key="<A 的 key>")      # 临时登录，不落盘
```

```bash
swanlab login --local                    # 凭据只写当前项目目录 .swanlab/
swanlab logout --local                   # 用完退出
```

仍要 `workspace="shanzhongxian"`，否则实验会落在 B 自己的用户名下。

> 官方原文提示：共用服务器时用 `swanlab.login(...)` 可避免“实验误传到别人账号”；`--local` 仅在 SDK ≥ 0.8.0 可用。

## 3. PyTRiO：B 怎么连

两种写法，效果等价：

```python
import pytrio
pytrio.configure(api_key="<key>", base_url="<平台地址>")   # 写入 ~/.pytrio/config.toml
```

或环境变量（推荐，不进代码）：

```powershell
$env:PYTRIO_API_KEY = "<key>"
$env:PYTRIO_BASE_URL = "<平台地址>"
```

验证：

```powershell
python src\train_pytrio.py --probe
```

返回 `{"ok": true, "stage": "sampling_client"}` 即连通。

> Key 是账号级的：B 用 A 的 key 就等于共用 A 的额度（企业赛 500 元代金券），用量无法分人。若不是同一账号，建议 B 用自己账号的 key。

## 4. 环境变量清单（B 机器必须设置）

| 变量 | 作用 | 示例 |
|---|---|---|
| `PYTRIO_API_KEY` | PyTRiO 鉴权 | `sk-...` |
| `PYTRIO_BASE_URL` | 平台地址（若官方给固定域名可不设） | `https://...` |
| `SWANLAB_API_KEY` | SwanLab 鉴权（方案甲/B 自己的 key） | `...` |
| `SWANLAB_LOGDIR` | 本地日志目录，**必须是 B 自己的路径** | `<训练机>\swanlog` |
| `SWANLAB_MODE` | `online`（有网）/ `local`（评测无网） | `online` |
| `HARNESS_DATA_ROOT` | 数据根目录（B 的盘符与 A 不同） | `<数据根目录>` |
| `HARNESS_RUNS_DIR` | 版本指针与决策日志目录（默认 `<repo>/runs`） | `<训练机>uns` |

## 5. B 的上手顺序

```powershell
# 1. 环境
python -m pip install -r packages/cpu-b-rul-20261110-v1/baselines/requirements.txt
python -m pip install swanlab pytrio

# 2. 连接性
python src\train_pytrio.py --probe
swanlab verify

# 3. 不训练的自检
python src\tests\test_adapter.py
python src\tests\test_runtime.py
python src\scripts\smoke.py

# 4. 首次训练（基线复现）
python src\project.py --profile all --epochs 5 --output-dir runs\round-1
```

## 6. 验收标准（A 侧怎么确认 B 连上了）

- B 的 `swanlab verify` 返回 `logged into https://swanlab.cn as <B>`；
- A 在 `swanlab.cn/@shanzhongxian/zhixun-engine` 能看到 B 新建的实验；
- B 的 `python src\train_pytrio.py --probe` 返回 `ok: true`；
- B 的 `runs/decisions.jsonl` 能通过 `python src\scripts\check_records.py`。
