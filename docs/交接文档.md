## 4. SwanLab 连接

- 项目：`zhixun-engine`
- 工作空间（项目所有者）：`shanzhongxian`
- API 主机：`https://api.swanlab.cn`
- 可见性：实验设为 `public=True`，评委可访问

**关键一行**：初始化时必须带 `workspace`，否则实验会建到你自己的空间，A 看不到。

```python
import swanlab

swanlab.init(
    project="zhixun-engine",
    workspace="shanzhongxian",
    experiment_name="A-round1",
    public=True,
)
```

两种权限模式（二选一）：

| 模式 | 做法 |
|---|---|
| 协作者（推荐） | A 在项目「概览 → 分享」里按用户名添加你，权限选「可开发」；你用自己的 key |
| 共用 key | 直接用 A 私聊给的 key；只在自己机器上用，用完 `swanlab logout` |

## 5. PyTRiO 连接

```powershell
python src\train_pytrio.py --probe
```

成功时返回：

```json
{"ok": true, "stage": "sampling_client", "model": "Qwen/Qwen3.8-27B"}
```

失败时 `stage` 会告诉你是 `credentials`（没 key）还是 `client`（key 无效/地址不对）。

> 注意：PyTRiO 只负责「读代码、改代码、决定跑什么」；**工业模型始终是 `project.py` 训练出来的 checkpoint**。

## 8. 训练入口的现状（重要）

`adapter/platform.py` 的批次循环**只做握手，不允许训练**：

```python
if allow_train:
    raise NotImplementedError("训练分支尚未接线（T02 只做握手）...")
```

所以现在有两条路：

| 路径 | 能做什么 | 限制 |
|---|---|---|
| `python src\project.py --profile A/B/C` | 直接续训，产出 checkpoint | 不经过 harness 的门禁与记录 |
| `python src\harness.py --profile A --strategy rule` | 走完整闭环（诊断→决策→门禁） | 会训练，属于“正式训练” |

交接阶段建议先用 `project.py` 跑基线，等 A 把批次接入训练后再用 `harness.py`。

## 11. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `swanlab` 不是命令 | 安装路径不在 PATH | 用 `py -m swanlab ...` |
| `swanlab login` 卡住 | 非交互终端 | 用 `-k <key>` 直接登录 |
| `ok: false, stage: credentials` | 没设 `PYTRIO_API_KEY` | 设环境变量后重试 |
| `stage: client` 报 401 | key 无效或 base_url 不对 | 找 A 确认 |
| 找不到 `packages/` | 没在仓库根目录执行 | `cd 智训引擎` 后再跑 |
| 中文乱码 | 控制台 GBK | `chcp 65001` |
