## 2. 术语

| 术语 | 含义 |
|---|---|
| profile | `A` 气体识别 / `B` 轴承 RUL / `C` 发动机 RUL |
| 批次 | B 包按批下发的 JSONL；处理完一批才能取下一批 |
| 候选 | 本轮续训产出的 `checkpoint.npz` |
| accepted / rejected | 门禁结论，写 `runs/decisions.jsonl` 的 `result` |
| no_op | `action=no_op`，不动版本指针，但仍要交产物 |
| 版本指针 | `runs/current.json`，记录 `checkpoint` / `previous` / `best_metric` / `rounds` |

```
inbox/
├── batch-0001.jsonl
├── batch-0001.meta.json   # 可选
```

- [ ] 根目录：默认 `./inbox`，可用 `HARNESS_BATCH_DIR` 覆盖 `【待确认】`
- [ ] 命名：`batch-0001.jsonl` `【待确认】`

### 3.2 字段（与公开数据完全一致）

`id` / `inputs` / `answer` / `meta.*`。
分组键沿用 `strategy/schemas.py::GROUP_KEYS`：
A `meta.source_batch`，B `meta.bearing`，C `meta.source_subset` + `meta.unit`。
**不要另造分组字段。**

读取实现：`src/adapter/batch.py::read_batch`，直接复用 `project.read_dataset` 校验
（特征 schema 一致、id 唯一、标签合法），因此批次与公开数据不会出现两套解析。

## 4. 产物协议 ⚠️

### 4.1 上线

```
submit/round-3/A/
├── checkpoint.npz
└── artifact.json
```

`artifact.json` 由 `src/adapter/artifact.py::write_artifact` 生成，字段：
`profile / round / checkpoint（相对路径）/ sha256 / primary_metric / value / gate / training_json`。

### 4.2 不上线

```
submit/round-3/A/no_op.json
{
  "profile": "A", "round": 3, "deploy": false, "reason": "no_op",
  "hypothesis": "...", "current_checkpoint": "runs/rounds/round-2/A/checkpoint.npz"
}
```

- [ ] no-op 表达方式 `【待确认】`
- [ ] 是否必须带当前模型 `【待确认】`

### 4.3 原子写

`atomic_write_bytes`：tmp → `fsync` → `os.replace`。指针最后更新，避免指针先动、文件没落地。

### 4.4 决策格式（照抄 `strategy/schemas.py`）

```json
{"action": "train|no_op|rollback", "hypothesis": "非空", "evidence_ids": ["drift_flag"], "params": {"lr_scale": 0.5, "epochs": 5, "patience": 2}}
```

参数只允许 tier-1 五个键；非法决策降级 `no_op`，`decision_source=fallback`。

## 6. 模型服务（PyTRiO）⚠️

| 项 | 值 |
|---|---|
| 模型 | `Qwen/Qwen3.8-27B`（默认，唯一模型） |
| 凭据 | `PYTRIO_API_KEY` 或 `~/.pytrio/config.toml` |
| 探测 | `python src/train_pytrio.py --probe` |
| 推理探针 | `--probe --generate`（≤32 token） |
| 训练开关 | `--run-training` **当前被拒绝**（首次训练未批准） |

代码对任何失败都返回 `{"ok": false, "stage": ...}`，并降级到规则决策，不抛栈。

### 6.1 推理参数基线（对照 PyTRiO 控制台）

| 控制台项 | 设成 | 理由 |
|---|---|---|
| Temperature | **0** | 决策要可复现；0.7 会让同一份诊断给出不同动作 |
| Top p | **1.0** | 温度 0 时无实际影响，保持一致即可 |
| 推理 Token 限制 | **512–1024** | 决策 JSON 只有 100–200 token；4096 只会让模型写长推理 |
| Enable thinking | **关** | 思考文本挤占 token，且容易把严格 JSON 冲坏 |
| Seed | **42** | 与 `pytrio_client.generate` 的 seed 一致，同输入同输出 |
| Presence / Frequency penalty | **0** | 决策不需要去重 |
| 停止词 | **空** | 加 `}` 之类会把 JSON 截断 |

代码侧对应 `src/pytrio_client.py` 的 `generate(..., temperature=0.0, top_p=1.0, thinking=False, seed=42)`，
`qwen_decide` 已按这套参数调用；控制台上的「官方模版」用来预览官方 prompt，**自己的 system 不要重复它**。
