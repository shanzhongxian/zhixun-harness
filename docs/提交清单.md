## 三、提交前必须跑通的命令

SDK 版（提交主链路）：

```powershell
py scripts\build_submit.py                       # 组装 submit/context（拒绝任何权重文件）
py app\_local_check.py A                         # 假宿主跑通 train + predict
$env:CONTEST_ROUNDS="2"; py app\_local_check.py A # /state 跨轮记忆
cd submit\context; docker build -t zhixun-harness:1.0.2 .
docker run --rm -i --entrypoint python3 zhixun-harness:1.0.2 /app/harness.py describe

# 容器内完整 train + 计时（4C8G、无网络）
$env:CONTEST_DOCKER="1"; py app\_local_check.py A   # wall≈2.5s
$env:CONTEST_DOCKER="1"; py app\_local_check.py B   # wall≈4.5s
$env:CONTEST_DOCKER="1"; py app\_local_check.py C   # wall≈19.8s
```

开发版（不进镜像）：

```powershell
python src\tests\test_adapter.py          # 适配层
python src\tests\test_runtime.py          # 预算/超时/兜底
python src\scripts\smoke.py               # 冒烟（不训练）
python src\scripts\handshake.py --real --profile A --batch-dir inbox_gas --submit-dir submit
python src\scripts\check_records.py       # 记录完整性
python src\scripts\drill_rollback.py      # 回滚演练 <30s
```
